# data/nutrition/

| File | What | Committed? |
|---|---|---|
| `indb.json` | INDB cooked-recipe table, per 100 g, with serving weights | **No** — generated by `scripts/import_indb.py` (the INDB repository has no licence file, so it is converted locally, not redistributed) |
| `portions.yaml` | Which serving units are countable pieces vs. containers | Yes |
| `plate_rules.yaml` | Balanced-plate rules and their one-sentence reads | Yes |

**Known gap.** INDB covers cooked recipes. Plain staples (plain curd, milk,
fruit, raw vegetables) live in ICMR-NIN IFCT 2017, which NIN distributes on
request only. Until it is added, such items are identified on the plate but
reported as "not priced" — never estimated by the model.
